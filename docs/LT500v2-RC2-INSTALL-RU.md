# LT500 v2 / R25 — OpenWrt 23.05.5, v2.0-zapret-rc2

Только для Cudy LT500 v2: board_name `cudy,lt500-v2`, MediaTek MT7628AN, флеш 16 МиБ.

В образ включены Zapret, LuCI, поддержка LTE CDC-ECM, Steer 2.0.3 и все шесть его модулей, TUN, AmneziaWG 2.0 с I1–I5, обновлённый netifd и Zapret Manager 2.48-2.
Отдельные патчи RC1 уже включены в RC2. Повторно устанавливать архивы модулей RC1 после прошивки RC2 не нужно: у RC2 свой ABI ядра.

Проверены метаданные платы, размер, состав пакетов, ABI всех 69 пакетов модулей и содержимое squashfs. Тесты сохранения настроек при обновлении панели и отката прошли.
Компоненты TUN/VLESS и AWG I1 проверены вами на RC1. Полный образ RC2 ещё требует проверки загрузки и туннелей на самом роутере.

## Переход с RC1 с сохранением настроек

На роутере сначала зарегистрируйте дополнительные настройки панели для сохранения:

```sh
umask 077
for p in /etc/zm-steer/ /etc/zm-awg/ /etc/zm-warp-own.conf /etc/steer/ /opt/zapret-manager-luci/state/; do
    grep -qxF "$p" /etc/sysupgrade.conf 2>/dev/null || echo "$p" >> /etc/sysupgrade.conf
done
sysupgrade -b /tmp/LT500v2-before-RC2.tar.gz
```

Скопируйте резервную копию `/tmp/LT500v2-before-RC2.tar.gz` на компьютер до прошивки: /tmp очищается при перезагрузке. Архив содержит настройки и ключи — храните его закрыто.

Скопируйте файл sysupgrade.bin в /tmp роутера. Проверьте хеш и образ:

```sh
IMG=/tmp/Cudy-LT500v2-OpenWrt-23.05.5-v2.0-zapret-rc2-sysupgrade.bin
sha256sum "$IMG"
sysupgrade -T "$IMG"
echo "test_rc=$?"
```

Хеш должен совпасть с указанным выше, test_rc должен быть 0. После успешной проверки:

```sh
sysupgrade "$IMG"
```

Команда сохраняет настройки и перезагружает роутер. Не используйте -F. После загрузки дайте около двух минут на установку панели. RC2 заменит сохранённую панель RC1 с сохранением её состояния.

## Проверки после загрузки

```sh
ubus call system board
df -h /overlay
modprobe tun
modprobe amneziawg
ls -l /dev/net/tun
awg --version
opkg list-installed | grep -E '^(steer-[^ ]+|kmod-tun|kmod-amneziawg|amneziawg-tools|zapret-manager-lt500) '
tail -n 40 /tmp/zapret-manager-bootstrap.log
```

Проверьте LTE-интернет, вашу подписку VLESS и WARP в панели. LuCI: Службы → Zapret Manager. Web UI: http://192.168.1.1:7788 (если адрес LAN сохранён другой, используйте его).

## Обновление панели отдельно от прошивки

Кнопка обновления использует совместимый канал пакетов LT500. Новые версии панели должны быть адаптированы и опубликованы в этом канале. Установка произвольного upstream-скрипта может стереть адаптацию LT500.

Ручная установка совместимого пакета:

```sh
opkg install /tmp/zapret-manager-lt500_2.48-2_mipsel_24kc.ipk
```

Этот пакет уже включён в RC2; устанавливать его сразу после прошивки не требуется. Для будущих обновлений используйте имя новой версии IPK.
Обновление сохраняет настройки и одну предыдущую версию панели. Требуется не менее 2300 КиБ свободного места в /overlay. Возможности, требующие нового ядра или драйвера, обновляются вместе с прошивкой.

Ручной откат панели:

```sh
/usr/libexec/lt500-panel-apply rollback
```

Откат сохраняет текущие настройки туннелей. Повторная автоматическая установка этой же версии блокируется до установки другого пакета панели или удаления `/etc/lt500-panel/rollback.sha256`.
