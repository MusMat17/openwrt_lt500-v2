# LT500v2 RC7 — исправление состояния WARP, панель 5.064-3

Обновление панели для RC7; перепрошивка, пересборка ядра и замена AmneziaWG не требуются.

Исправлен воспроизводимый сценарий: после удаления/повторной установки Steer в UCI остаются zmwarp и zmwarp3, а в реестре владельца — только zmwarp2. Сохранённые ключи уже не соответствуют оставшимся интерфейсам. Туннели работают при проверке, но панель считает WARP выключенным; удаление убирает только второй интерфейс.

Панель восстанавливает реестр и локальный кэш ключей из действующей конфигурации UCI. Для интерфейса без отметки владельца проверяются зарезервированное имя, тип пира, публичный ключ Cloudflare, исходное описание панели и выключенный route_allowed_ips. Совпадения только имени недостаточно. Чужие интерфейсы с другими признаками сохраняются. Работающие ключи и endpoint в UCI при восстановлении не меняются.

Восстановление выполняется при проверке состояния, перед настройкой WARP и в обоих сценариях удаления. При обновлении заменяются только три файла кода backend; остальные настройки и активные интерфейсы сохраняются. Старая версия этих файлов сохраняется в /root/lt500-warp-state-backup.tar.gz. Повторное применение не заменяет эту резервную копию.

## Установка на RC7

Дождитесь завершения операций в панели. Откройте Zapret Manager → обновление панели: версия 5.064-3 доступна через совместимый канал LT500 Lite.

Для ручной установки скопируйте zapret-manager-lt500_5.064-3_mipsel_24kc.ipk в /tmp, сверьте его SHA256 с WARP-FIX-SHA256SUMS и выполните:

~~~sh
opkg install /tmp/zapret-manager-lt500_5.064-3_mipsel_24kc.ipk
~~~

Не нужны opkg update, --force-depends или изменение прав на /etc/zm-steer. Проверяйте вывод opkg и /tmp/zapret-manager-bootstrap.log: ошибки установки нельзя игнорировать.

Обновите страницу панели и примените настройки Steer. Повторный подбор точек WARP обычно не требуется, если прежние интерфейсы отвечают. После этого ещё раз обновите страницу: WARP должен оставаться настроенным. Для удаления используйте действие удаления WARP или Steer в панели — отметки восстановятся перед очисткой.

Встроенный компонент AmneziaWG по-прежнему защищён от удаления через панель: это модуль именно нашего ядра. Защита компонента не запрещает удалять принадлежащие Steer туннели.

Тесты воспроизводят исходную ошибку и проверяют восстановление, новый процесс панели, все три туннеля, удаление, отказ от присвоения чужого интерфейса, синтаксис, установку штатным MIPS opkg и откат при ошибке копирования. Холодный запуск и реальный трафик WARP на устройстве требуют проверки владельцем.

Исходный образ RC7 не заменён. При новой установке RC7 примените это обновление панели. RC6 и более ранние релизы сохранены.
