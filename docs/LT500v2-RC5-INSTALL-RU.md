# Cudy LT500v2 / R25 — OpenWrt 23.05.5 — RC5 Zapret Bundle

Только для **Cudy LT500 v2 / R25**: `cudy,lt500-v2`, MT7628AN, 128 МиБ RAM, 16 МиБ флеш.

## Состав RC5

- Zapret Manager **5.064-1**, исходники `be2baf3db38dcefafc104a5460fe5829315ab514`.
- Steer **2.1.3-1**, исходники `9e05393b9747f4f85cd1ede38e34d03c6583b187`. Используется официальный пакет с соответствующими ключами проверки и подписанным офлайн-набором плагинов; net1 **1.4.3**. Исправления Steer 2.1.3 для opkg OpenWrt 23.05 и nft redirect Linux 5.15 включены upstream.
- Радио удалено из кода Web UI, backend, RPC/ACL и стилей; каталога станций и аудиоплеера в панели нет. Wi-Fi сохранён. Удалено около 58 КБ до сжатия.
- OpenWrt 23.05.5 / Linux 5.15.167, LuCI, LTE CDC-ECM, curl, unzip и Zapret 72.20260307.
- TUN и AmneziaWG 2.0 с I1–I5, собранные вместе с ядром. Рабочая аппаратная база и исходники AWG сохранены из RC2.
- Обновление панели отдельным совместимым IPK, сохранение настроек и откат предыдущей панели.

Автоматическое переключение WAN/4G и mwan3 не добавлены. Переключение остаётся ручным.

## Проверка файла

Образ: `Cudy-LT500v2-OpenWrt-23.05.5-v2.0-zapret-rc5-sysupgrade.bin`.
Размер: **@IMAGE_BYTES@ байт**.
SHA256: `@IMAGE_SHA256@`.
Пакет ядра: `@KERNEL_VERSION@`.

В ZIP находятся образ, инструкции, манифесты, контрольные суммы, IPK панели и пакеты Steer. Для обычной перепрошивки нужен только `sysupgrade.bin`. Содержимое архива можно проверить командой `sha256sum -c SHA256SUMS` на компьютере с этой утилитой. Контрольная сумма самого ZIP опубликована отдельным файлом `.zip.sha256`.

## Обновление с нашей RC1 / RC2 / RC3 / RC4 с сохранением настроек

Сначала сохраните резервную копию:

```sh
umask 077
for p in /etc/zm-steer/ /etc/zm-awg/ /etc/zm-warp-own.conf /etc/steer/ /opt/zapret-manager-luci/state/ /opt/zapret-manager-luci/dns_net /etc/zapret_manager_expert_mode; do
    grep -qxF "$p" /etc/sysupgrade.conf 2>/dev/null || echo "$p" >> /etc/sysupgrade.conf
done
sysupgrade -b /tmp/LT500v2-before-RC5.tar.gz
```

**Скопируйте архив резервной копии на компьютер до прошивки.** В `/tmp` он исчезнет при перезагрузке. Архив содержит ключи и настройки — храните его закрыто.

Перед обновлением дождитесь завершения операций в Zapret Manager. Скопируйте образ в `/tmp`, затем проверьте хеш и совместимость:

```sh
IMG=/tmp/Cudy-LT500v2-OpenWrt-23.05.5-v2.0-zapret-rc5-sysupgrade.bin
sha256sum "$IMG"
sysupgrade -T "$IMG"
echo "test_rc=$?"
```

Хеш должен совпасть с указанным выше, а `test_rc` должен быть **0**. После успешной проверки:

```sh
sysupgrade "$IMG"
```

Сохраняются штатные настройки OpenWrt и перечисленные выше настройки панели. После перезагрузки дайте около двух минут на установку новой панели. **Не используйте `-F`.** Для чистой установки используйте `sysupgrade -n` только после сохранения резервной копии.

На заводскую Cudy эта команда не рассчитана. Первичная установка: **заводская Cudy → промежуточная OpenWrt от Cudy именно для LT500v2 → наш sysupgrade**. Заводские настройки в OpenWrt не переносите.

## Переход Steer 2.0 → 2.1

Протоколы теперь устанавливаются как подписанные плагины `.s2p`, а не отдельные `steer-vless.ipk` и подобные пакеты. В прошивке сохранён официальный офлайн-набор VLESS, Hysteria2, Proxy, XSteer, Obfs, WARPBox и их зависимости net1/AWG. При первом запуске после sysupgrade устанавливаются плагины, необходимые сохранённой спецификации `/etc/steer/spec.json` или `spec.yaml`; неиспользуемые протоколы не дублируются в overlay. Панель устанавливает нужные плагины при применении настроек.

**TGWS не входит в официальный офлайн-набор 2.1.3.** Если вы его используете, после обновления потребуется сеть и установка подписанного плагина TGWS из upstream-репозитория через менеджер плагинов Steer. Старый IPK TGWS 2.0.5 не устанавливайте. Перед перепрошивкой предусмотрите временный доступ через другой протокол.

Проверка переноса:

```sh
cat /tmp/lt500-steer-migrate.log
steer plugin list
steer plugin status
```

На чистой прошивке без сохранённой спецификации миграция не требуется и журнал может отсутствовать. При ошибке миграции повторите `/usr/libexec/lt500-steer-migrate`, затем `/etc/init.d/steer restart`. Проверка миграции в CI использует настоящий userspace RC4 и эмуляцию MIPS: это проверка совместимости, подписей и зависимостей; не проверка трафика на роутере.

## Проверки после загрузки

```sh
ubus call system board
cat /etc/lt500-allinone
df -h /overlay
modprobe tun
modprobe amneziawg
ls -l /dev/net/tun
steer --version
opkg list-installed | grep -E '^(steer-[^ ]+|kmod-tun|kmod-amneziawg|amneziawg-tools|zapret-manager-lt500) '
tail -n 40 /tmp/zapret-manager-bootstrap.log
```

Проверьте проводной WAN, LTE, сохранённую подписку VLESS и WARP. LuCI: **Службы → Zapret Manager**. Web UI: `http://192.168.1.1:7788` (при сохранённом другом LAN-адресе используйте его).

## Обновление панели и откат

Кнопка обновления обращается к совместимому каналу **lt500-panel-steer213-noradio** в нашем репозитории. Предыдущие каналы, включая RC4 `lt500-panel-steer205-v4`, сохранены отдельно. В новый канал публикуются адаптированные панели без радио. Дальнейшие версии панели нужно адаптировать и опубликовать в совместимом канале; произвольный upstream-установщик может стереть адаптацию LT500.

Ручная установка совместимого пакета:

```sh
opkg install /tmp/zapret-manager-lt500_5.064-1_mipsel_24kc.ipk
```

В RC5 этот пакет уже установлен. Для будущего обновления используйте имя нового совместимого IPK. Обновление требует **3200 КиБ свободного места в `/overlay`**; сохраняет настройки и одну сжатую копию предыдущей панели. При ошибке установки прежняя панель и настройки возвращаются автоматически.

Ручной откат панели:

```sh
/usr/libexec/lt500-panel-apply rollback
```

Откат сохраняет текущие настройки туннелей и закрепляет предыдущую панель до установки пакета с другим установщиком либо удаления `/etc/lt500-panel/rollback.sha256`.

Zapret и модули ядра AmneziaWG защищены от замены внешними пакетами через панель. Возможности, требующие новых модулей ядра, обновляются с прошивкой. Старые архивы kmod из RC1 на RC5 не устанавливайте.

## Статус проверки

RC5 — предварительный выпуск. Проверки сборки контролируют версии панели, Steer и подписанных плагинов, метаданные платы, размер образа, ABI каждого kmod, TUN/AWG/UDP-зависимости, синтаксис всех генерируемых файлов панели и отсутствие радио, защиту встроенных пакетов, обновление и откат панели. Проверка загрузки, LTE и туннелей именно на вашем роутере выполняется после установки.
