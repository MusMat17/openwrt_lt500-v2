# Cudy LT500v2 — OpenWrt 23.05.5 — RC7

Только Cudy LT500 **v2**, board_name: cudy,lt500-v2. Это предварительный релиз для проверки на устройстве.

Изменения относительно RC6:

- Zapret включается при первом запуске RC7. Исправлено отсутствие автозапуска в предыдущем образе. Последующее ручное отключение сохраняется.
- Включён список РКН Tachyon Lists ru_blocked: кэш входит в образ, ежедневное обновление атомарное. Ошибка скачивания сохраняет последний список. YouTube исключён из этого списка, чтобы сохранить отдельную стратегию.
- В существующих стратегиях заменяются только стандартные HOSTLIST-плейсхолдеры. Специальная стратегия без них сохраняется; список можно выбрать вручную в панели, если она поддерживает этот режим.
- Zapret Manager 5.064-2 LT500 Lite: физически удалены темы, внешние шрифты, анимации и оформление фона. Радио отсутствует.
- Исправлено восстановление WARP после подбора endpoint: сохранённые ключи сверяются с интерфейсом, отметка владения восстанавливается. Ошибка применения больше не завершается ложным сообщением об успехе.
- Steer 2.1.4, ядро 5.15.167, все 69 модулей ядра и рабочий AmneziaWG I1 из RC6 сохранены без изменений.
- Панель можно обновлять отдельно совместимым IPK через канал LT500 Lite.

Автоматические проверки не заменяют проверку холодного запуска и WARP на вашем роутере. Реальный регион выхода WARP определяется Cloudflare; исправление состояния не меняет геолокацию IP.

## Установка

Сохраните резервную копию настроек из LuCI. Скопируйте sysupgrade.bin в /tmp роутера.

Размер образа: @IMAGE_BYTES@ байт.
SHA256: @IMAGE_SHA256@

Проверьте:
~~~sh
cat /tmp/sysinfo/board_name
sha256sum /tmp/Cudy-LT500v2-OpenWrt-23.05.5-v2.0-zapret-rc7-sysupgrade.bin
sysupgrade -T /tmp/Cudy-LT500v2-OpenWrt-23.05.5-v2.0-zapret-rc7-sysupgrade.bin
~~~

При board_name cudy,lt500-v2, совпавшем SHA256 и успешном тесте:
~~~sh
sysupgrade /tmp/Cudy-LT500v2-OpenWrt-23.05.5-v2.0-zapret-rc7-sysupgrade.bin
~~~

Не применяйте -F. Для сохранения настроек не используйте -n.

Панель устанавливается из локального пакета после загрузки. На одноядерном LT500 дайте ей завершить установку; проверьте /tmp/zapret-manager-bootstrap.log. Откройте http://192.168.1.1:7788 и обновите страницу без кэша.

## Проверка после запуска

~~~sh
/etc/init.d/zapret enabled; echo "enabled_rc=$?"
uci -q get zapret.config.run_on_boot
pgrep -f /opt/zapret/nfq/nfqws
logread | grep -E 'lt500-zapret|lt500-rkn'
~~~

Для WARP повторите настройку и обновите страницу. Выбранные сервисы/устройства должны быть сохранены, Steer — активен. Если сервисы не выбраны, панель может держать Steer выключенным.

Если раньше выставлялась привязка панели после ручного rollback, сбросьте её осознанно командой:
~~~sh
rm -f /etc/lt500-panel/rollback.sha256
/usr/libexec/lt500-panel-apply
~~~

Отдельные пакеты не требуют прошивки ядра. Панель 5.064-2 исправляет WARP и убирает оформление; lt500-bundle-support добавляет список и автозапуск Zapret. Все IPK предназначены для совместимого LT500 bundle. Не устанавливайте внешние kmod-пакеты с чужим ABI.

RC6 и RC5 сохранены для отката. ZIP содержит образ, IPK, манифесты, контрольные суммы и эти инструкции.
