# Cudy LT500v2 / R25 — OpenWrt 23.05.5 — RC3 Zapret Bundle

Только для **Cudy LT500 v2 / R25**: `cudy,lt500-v2`, MT7628AN, 128 МиБ RAM, 16 МиБ флеш.

## Состав RC3

- Zapret Manager **3.43-1**, исходники `61263e50faeba2461e30d7fcc54f1fdb75ef1e21`.
- Steer **2.0.5-1** и все шесть модулей: VLESS, Hysteria2, Proxy, XSteer, Obfs, TGWS; исходники `239c2897a726bc66dbe1900a3f4595d4d9b5f62d`.
- OpenWrt 23.05.5 / Linux 5.15.167, LuCI, LTE CDC-ECM, curl, unzip и Zapret 72.20260307.
- TUN и AmneziaWG 2.0 с I1–I5, собранные вместе с ядром. Рабочая аппаратная база и исходники AWG сохранены из RC2.
- Обновление панели отдельным совместимым IPK, сохранение настроек и откат предыдущей панели.

Автоматическое переключение WAN/4G и mwan3 не добавлены. Переключение остаётся ручным.

## Проверка файла

Образ: `Cudy-LT500v2-OpenWrt-23.05.5-v2.0-zapret-rc3-sysupgrade.bin`.
Размер: **@IMAGE_BYTES@ байт**.
SHA256: `@IMAGE_SHA256@`.
Пакет ядра: `@KERNEL_VERSION@`.

В ZIP находятся образ, инструкции, манифесты, контрольные суммы, IPK панели и пакеты Steer. Для обычной перепрошивки нужен только `sysupgrade.bin`. Содержимое архива можно проверить командой `sha256sum -c SHA256SUMS` на компьютере с этой утилитой. Контрольная сумма самого ZIP опубликована отдельным файлом `.zip.sha256`.

## Обновление с нашей RC1 / RC2 с сохранением настроек

Сначала сохраните резервную копию:

```sh
umask 077
for p in /etc/zm-steer/ /etc/zm-awg/ /etc/zm-warp-own.conf /etc/steer/ /opt/zapret-manager-luci/state/ /opt/zapret-manager-luci/dns_net /etc/zapret_manager_expert_mode; do
    grep -qxF "$p" /etc/sysupgrade.conf 2>/dev/null || echo "$p" >> /etc/sysupgrade.conf
done
sysupgrade -b /tmp/LT500v2-before-RC3.tar.gz
```

**Скопируйте архив резервной копии на компьютер до прошивки.** В `/tmp` он исчезнет при перезагрузке. Архив содержит ключи и настройки — храните его закрыто.

Перед обновлением дождитесь завершения операций в Zapret Manager. Скопируйте образ в `/tmp`, затем проверьте хеш и совместимость:

```sh
IMG=/tmp/Cudy-LT500v2-OpenWrt-23.05.5-v2.0-zapret-rc3-sysupgrade.bin
sha256sum "$IMG"
sysupgrade -T "$IMG"
echo "test_rc=$?"
```

Хеш должен совпасть с указанным выше, а `test_rc` должен быть **0**. После успешной проверки:

```sh
sysupgrade "$IMG"
```

Сохраняются штатные настройки OpenWrt и перечисленные выше настройки панели. После перезагрузки дайте около двух минут на установку новой панели. **Не используйте `-F`.** Для чистой установки используйте `sysupgrade -n` только после сохранения резервной копии.

На заводскую Cudy эта команда не рассчитана. Первичная установка: **заводская Cudy → промежуточная OpenWrt от Cudy именно для LT500v2 → наш sysupgrade**. Заводские настройки в OpenWrt не переносите.

## Проверки после загрузки

```sh
ubus call system board
cat /etc/lt500-allinone
df -h /overlay
modprobe tun
modprobe amneziawg
ls -l /dev/net/tun
steer --version
opkg list-installed | grep -E '^(steer-[^ ]+|kmod-tun|kmod-amneziawg|amneziawg-tools|zapret-manager-lt500) '
tail -n 40 /tmp/zapret-manager-bootstrap.log
```

Проверьте проводной WAN, LTE, сохранённую подписку VLESS и WARP. LuCI: **Службы → Zapret Manager**. Web UI: `http://192.168.1.1:7788` (при сохранённом другом LAN-адресе используйте его).

## Обновление панели и откат

Кнопка обновления обращается к совместимому каналу **lt500-panel-steer205** в нашем репозитории. Канал RC2 `lt500-panel-stable` сохранён отдельно: панель 3.x не подменяет обновление на старой прошивке. Дальнейшие версии панели нужно адаптировать и опубликовать в совместимом канале; произвольный upstream-установщик может стереть адаптацию LT500.

Ручная установка совместимого пакета:

```sh
opkg install /tmp/zapret-manager-lt500_3.43-1_mipsel_24kc.ipk
```

В RC3 этот пакет уже установлен. Для будущего обновления используйте имя нового совместимого IPK. Обновление требует **3200 КиБ свободного места в `/overlay`**; сохраняет настройки и одну сжатую копию предыдущей панели. При ошибке установки прежняя панель и настройки возвращаются автоматически.

Ручной откат панели:

```sh
/usr/libexec/lt500-panel-apply rollback
```

Откат сохраняет текущие настройки туннелей и закрепляет предыдущую панель до установки пакета с другим установщиком либо удаления `/etc/lt500-panel/rollback.sha256`.

Zapret и модули ядра AmneziaWG защищены от замены внешними пакетами через панель. Возможности, требующие новых модулей ядра, обновляются с прошивкой. Старые архивы kmod из RC1 на RC3 не устанавливайте.

## Статус проверки

RC3 — предварительный выпуск. Проверки сборки контролируют версии панели и всех модулей Steer, метаданные платы, размер образа, ABI каждого kmod, TUN/AWG/UDP-зависимости, синтаксис настоящего backend панели, защиту встроенных пакетов, обновление и откат панели. Проверка загрузки, LTE и туннелей именно на вашем роутере выполняется после установки.
