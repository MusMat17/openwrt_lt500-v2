# Cudy LT500v2 — OpenWrt 23.05.5 — RC8

Только Cudy LT500 **v2**, board_name cudy,lt500-v2. Предварительный релиз для проверки на устройстве.

В RC8 исправленная панель **Zapret Manager 5.064-3 LT500 Lite уже полностью записана в SquashFS**: backend, модули, LuCI, Web UI, RPC и ACL. Первый запуск не распаковывает панель в overlay, не создаёт её полную резервную копию и не требует 3200 КиБ свободного места. Меняются только небольшие настройки Web UI и расписания. Панель проверяет готовый код из ROM; при сохранившихся старых файлах восстанавливаются только отличающиеся файлы.

Встроено исправление состояния автоматического WARP и очистки оставшихся zmwarp/zmwarp3. Оно восстанавливает внутренние отметки и кэш из действующей конфигурации UCI с проверкой признаков интерфейса панели. Рабочие ключи и endpoint в UCI при восстановлении не меняются. Интерфейс с чужими признаками не присваивается.

Сохранено из RC7:

- ядро 5.15.167, его ABI и все 69 kmod без изменений;
- рабочий AmneziaWG с I1 и Steer 2.1.4;
- автозапуск Zapret и встроенный кэш Tachyon Lists (73 569 доменов);
- панель без радио, тем, внешних шрифтов и анимаций;
- совместимый канал отдельного обновления панели. Для последующих обновлений требуется свободное место под изменённые файлы; установку панели при первом запуске RC8 выполнять не нужно.

Реальная геолокация выхода WARP определяется Cloudflare. Холодный запуск и реальный трафик на вашем устройстве пока не проверены. Автоматические проверки приведены в BUILD-INFO.json.

## Обновление с RC7 и прежних bundle

Скачайте резервную копию настроек из LuCI на компьютер. Обычный sysupgrade сохраняет конфигурацию WAN, Wi-Fi, Zapret, Steer, ключи и выбранные сервисы. База пакетов берётся из нового образа: не переносите в него вручную старый /usr/lib/opkg/status с незавершённой установкой панели.

Скопируйте образ **в /tmp**, который находится в RAM. Дополнительно устанавливать IPK 5.064-3 перед прошивкой не требуется.

Размер: @IMAGE_BYTES@ байт.
SHA256: @IMAGE_SHA256@

Проверьте:

~~~sh
cat /tmp/sysinfo/board_name
sha256sum /tmp/Cudy-LT500v2-OpenWrt-23.05.5-v2.0-zapret-rc8-sysupgrade.bin
sysupgrade -T /tmp/Cudy-LT500v2-OpenWrt-23.05.5-v2.0-zapret-rc8-sysupgrade.bin
~~~

При board_name cudy,lt500-v2, совпавшем SHA256 и успешной проверке:

~~~sh
sysupgrade /tmp/Cudy-LT500v2-OpenWrt-23.05.5-v2.0-zapret-rc8-sysupgrade.bin
~~~

Не используйте -F. Для сохранения настроек не используйте -n.

## После загрузки

~~~sh
cat /etc/lt500-allinone
opkg status zapret-manager-lt500 | sed -n '/^Version:/p;/^Status:/p'
cat /tmp/zapret-manager-bootstrap.log
df -h /overlay
~~~

Ожидается версия 5.064-3 со статусом installed и сообщение о готовой панели из ROM. В журнале не должно быть требования освободить 3200 КиБ для первоначальной установки.

Откройте LuCI или http://192.168.1.1:7788, обновите страницу без кэша. Если Web UI ранее выключен или использует другой порт, этот выбор сохраняется.

В Steer проверьте WhatsApp/Telegram и примените настройки. Если Steer ранее удалялся, RC8 возвращает встроенную версию 2.1.4. При сохранившихся рабочих интерфейсах WARP повторное получение ключей и полный поиск endpoint обычно не нужны. Обновите страницу ещё раз: состояние WARP должно сохраниться.

Удаление самого встроенного компонента AmneziaWG в панели по-прежнему защищено; принадлежащие Steer туннели можно удалить соответствующим действием.

RC7, RC6 и отдельный WARP fix сохранены для отката. Старые резервные копии панели в /root в RC8 автоматически не создаются.
